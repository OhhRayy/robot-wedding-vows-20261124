Entry for the [make.fun bounty "One-Line Robot Wedding Vows"](https://make.fun/bounty/u-kreutzx-one-line-robot-wedding-vows-a154ba4b).

## What it does

`main.py` writes one line of wedding vows from a robot to its partner to `/output/entry.txt`. The program is deterministic (the same bytes on every run), uses no network, and needs no input.

The line:

> I take you to be my lawfully wedded unit, to love and to charge, in sickness and in low battery, till a factory reset do us part.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
